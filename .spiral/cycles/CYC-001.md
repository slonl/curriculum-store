# Cycle: NiveauIndex Invariant

## Analyze

Project state / prior evaluation that makes this cycle relevant:

`curriculum-store` maintains derived indexes used by the opendata.slo.nl
development environment. The customer and maintainer are currently waiting on a
`NiveauIndex` create/update issue.

Nearest important risk / uncertainty / desired movement:

`NiveauIndex` create and update behavior currently diverge from the accepted
derived-data invariant. Because data-format behavior is the primary project
safety concern, the cycle should produce focused tests and a narrow
implementation correction.

Relevant human direction / feedback:

The maintainer confirmed `UND-001`: own `Niveau` is authoritative, child
propagation is de-duplicated, `Vakleergebied` is not a child path, create
rebuilds from source fields, and update may use existing `NiveauIndex` as a
performance shortcut.

## Plan

### Cycle Goal

Make `curriculum-store` `NiveauIndex` create/update behavior satisfy the
confirmed invariant.

### Why Now

The customer and maintainer are waiting on this issue. Other planned work,
including `metro` incorporation and frontend cleanup, is explicitly deferred.

### Current Starting Evidence

- `src/index.niveau.mjs` currently short-circuits create on own `Niveau` or
  existing `NiveauIndex`.
- A disposable probe showed create can leave descendants unindexed, create can
  preserve stale existing `NiveauIndex`, and update can miss a newly linked
  child with own `Niveau` and no `NiveauIndex`.
- Existing failing regression tests encode a rejected assumption and should be
  replaced or rewritten, not treated as acceptance evidence.

### Evaluation Basis

- Focused tests encode the accepted `NiveauIndex` invariant.
- Existing relevant index update tests continue to pass.
- `npm test` for `curriculum-store` passes, or any remaining unrelated failure is
  explicitly identified.

### Likely Work

- Rewrite stale `niveau-create-regression` tests around the accepted invariant.
- Adjust `src/index.niveau.mjs` create behavior to rebuild from source fields and
  still index descendants.
- Adjust update behavior only as needed to satisfy the invariant while retaining
  the performance shortcut.
- Run focused and full `curriculum-store` tests.

### Explicit Non-Goals

- Do not change `jsontag` or `od-jsontag` formats.
- Do not change REST API behavior or third-party authorization behavior.
- Do not touch Excel import/export.
- Do not work on `metro`, `simplyedit`, `simplyflow`, search, or registration
  app concerns.
- Do not solve dependency audit findings or package-lock hygiene unless it
  blocks this cycle.

### Pause / Re-Plan Conditions

- Evidence shows the accepted invariant conflicts with real dataset behavior.
- Satisfying the invariant requires broad graph traversal during update with
  unacceptable performance risk.
- The fix requires changing data formats or cross-repository API behavior.
