# Verification Evidence: NiveauIndex Invariant Tests

## Claim Being Verified

`IMP-001` realizes `DES-001`: `NiveauIndex` create/update behavior satisfies
the accepted invariant for own `Niveau`, child propagation, de-duplication,
derived create state, newly linked children, and `Vakleergebied` exclusion.

## Why This Evidence Exists

The cycle changed derived index behavior in a data-sensitive area. Focused tests
and existing update/import tests provide evidence that the implementation
matches the intended invariant and does not regress nearby index behavior.

## Failure Cases / Limits

- This evidence does not characterize update performance on a full
  production-like dataset.
- This evidence does not include Docker startup or manual UI/editing checks.
- The normal `npm test` command remains blocked as a green-exit CI signal by
  existing 100% coverage thresholds unless coverage improves or the threshold is
  reconfigured.
- Lint remains blocked until the project has an ESLint v9 flat config or uses a
  compatible ESLint version/configuration.

## Evidence Quality

The focused tests encode the human-confirmed invariant rather than the stale
regression assumptions. They include cases that failed under the pre-change
implementation: descendants below authoritative parents, stale existing
`NiveauIndex` during create, newly linked children without populated
`NiveauIndex`, and parent own `Niveau` remaining authoritative during child
updates.
