# Implementation: NiveauIndex Create/Update Derivation

## Scope

The `curriculum-store` implementation that derives `NiveauIndex` during index
create and update.

## Observable Behavior

- Create rebuilds `NiveauIndex` from source `Niveau` fields and graph relations.
- Create indexes descendants even when an ancestor has authoritative own
  `Niveau`.
- Existing derived `NiveauIndex` is not treated as source state during create.
- Update derives from existing child `NiveauIndex` when available, but can
  populate a child from own `Niveau` when the child is newly linked without an
  index.
- Own `Niveau` remains authoritative during update and child changes do not
  override it.
- `Vakleergebied` remains excluded from niveau propagation.

## Important Implementation Decisions

- A shared local `calculateNiveauIndex` helper is used by create and update so
  they cannot easily drift into different interpretations of the invariant.
- Create passes `rebuildChildren: true`, causing descendants to be rebuilt from
  source state before parent values are assigned.
- Update passes `rebuildChildren: false`, preserving the performance shortcut of
  existing child indexes where possible.
- Existing empty child `NiveauIndex` can remain a shortcut when the child has no
  own `Niveau`; missing child indexes or children with own `Niveau` are rebuilt
  locally.
