# Understanding: NiveauIndex Derived Invariant

## Current Interpretation

`NiveauIndex` is derived materialized data used to filter graph entities by
their effective `Niveau`.

For each entity:

- if the entity has its own `Niveau`, its `NiveauIndex` is exactly that
  de-duplicated list;
- if the entity has no own `Niveau`, its `NiveauIndex` is the de-duplicated
  union of relevant child `NiveauIndex` values;
- a node's own `Niveau` is authoritative from that node upward, so descendants
  do not contribute additional levels through that node;
- `Vakleergebied` is a related relation, not a child propagation path;
- `create` rebuilds `NiveauIndex` from source fields and graph relations, not
  from existing persisted `NiveauIndex`;
- `update` may use existing `NiveauIndex` as a performance shortcut when
  possible.

## Sources Considered

- `SRC-001`: maintainer clarification during Spiral startup.
- Current `src/index.niveau.mjs` behavior.
- Current tests, including the stale failing regression file whose assumptions

## Current Effective Behavior / Evidenced Gap

Current `src/index.niveau.mjs` behavior diverges from this understanding:

- `registerNiveauIndex` stops descending when an entity has own `Niveau`, so
  descendants may not receive their own `NiveauIndex` during create.
- `registerNiveauIndex` treats existing `NiveauIndex` as input during create,
  even though it is derived data.
- `updateNiveauIndex` derives from child `NiveauIndex` values, but a newly
  linked child with own `Niveau` and no populated `NiveauIndex` does not
  contribute during that update.

A disposable runtime probe on the current implementation observed:

```text
create authoritative root {"root":["root-level"],"child":[]}
create stale existing index {"root":["root-level"],"child":[]}
update new child without index {"root":[],"child":[]}
```

The first result has the authoritative root value but leaves the child
unindexed. The second result preserves stale existing derived data instead of
rebuilding from child source state. The third result misses a newly linked
child's own `Niveau`.

## Provenance Confidence

Evidenced.

## Remaining Uncertainty

The exact performance envelope for update is not characterized. The current
cycle should avoid broad full-graph recalculation during update unless evidence
shows it is necessary.

## Consequence

Create a request and design for focused `NiveauIndex` create/update behavior
that satisfies this invariant, replacing stale regression expectations with
tests that encode the accepted model.
